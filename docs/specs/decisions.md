# Yoin v0 已确认决策

本文记录 2026-10-26 讨论结论；与原始实现说明冲突时，以本文为准。

- 名称：**Yoin（余韵）— Your Own Inner Nook**。
- v0 验证 agent 循环跑通；占位音色的真实感与好听程度不作为验收门槛。
- 配方合法性属于硬约束；混音建议不阻止提交。出现建议后至少尝试一次调整，仍保留的建议应解释取舍。
- 宽频段能量差只提示“可能被掩盖”；能量占比高是检查提示，可能符合场景设计。
- 继续调整默认最小修改，保留 seed、稳定 layer_id 和无关参数；用户最新要求优先于模板建议。
- 保留 -24 LUFS 总线归一化和 -1 dBFS 峰值上限。音量和距离控制相对关系；距离衰减测试检查总线归一化之前的信号。
- 渲染器只接收具体配方和声音库；模板和指导文字在生成配方时使用，不参与 DSP。
- 配方预留 schema_version 和稳定 layer_id；声音描述支持默认 0 dB 的 gain_db，以及可选的音乐信息。
- 模板采用“设计说明 Markdown + 参考 recipe JSON”。模板中的角色描述不改变渲染公式。
- 独立维护声音资料、场景模板、调参指南和试听案例。v0 不实现模板检索、模板编辑器或时间编排。
- 后续 agent 运行记录实际使用的 prompt、规则、模板、渲染器版本与声音库信息。

## 阶段 1（已完成）

实现第一个 ticket：不经过大模型，用占位声音和手写配方生成 WAV，并验收渲染行为。
首轮仅创建阶段 2–4 tickets，没有提前实现后续功能。

阶段 1 的工程约定：

- Python 3.11+，48000 Hz，内部及 WAV 使用 float32。生成的 WAV 和运行输出不进入 Git。
- `library.json` 顶层采用声音描述数组；素材路径相对该文件所在目录解析。
- CLI 默认在当前目录读取声音库与规则，可通过 `YOIN_PROJECT_DIR` 指定项目目录。
- 渲染时长为 1–300 秒的整数；默认 30 秒。混响尾部截取为请求时长。
- 同一环境、配方、素材、种子和时长产生相同数组。各层和房间使用独立的随机流。
- event 频率为 0 时不触发。静音或低于响度测量门限时，不做响度提升，响度以 null 表示。
- 返回混音、包含各层混响贡献的单轨、总线增益及归一化前后的测量。单轨应用相同总线增益。
- 缺省 layer_id 根据 sound_id 生成；重复素材自动编号。显式 layer_id 必须唯一。
- gain_db 为素材校准增益，范围 -60 到 24 dB，独立于配方音量。

## 本轮：阶段 2–3

用户要求继续直到接完 agent 循环。完成分析器、两工具循环、模板与指导注入和全过程产物。
继续调整与评分仍属于阶段 4。

- 分离工具执行成功 `success` 与没有混音建议 `ok`，建议允许带入最终结果。
- 规则支持逐项开关和 info／warning 提示级别，两者均不阻止提交。
- 能量占比的分母是各单轨能量之和；混音本身包含相干交叉项，另行测量。
- 单侧完全静音时，声道差值为 null，并记录静音侧；双侧静音的差值为 0。
- 初稿与终稿默认均为 120 秒；试听默认 30 秒。八轮指模型请求上限。
- 真实模型通过环境变量配置；自动化测试使用模拟响应及本地兼容 HTTP 服务，不要求付费密钥。
- 四次试听后提交已试听的配方；标题、种子、层命名和单纯换序不计为参数调整。
- 模型服务故障且已有有效试听时保存兜底结果；用户中断时保存失败状态和已有产物。
- 运行快照记录实际使用的内容与素材 SHA256，不复制音频，也不保存认证头或密钥。
