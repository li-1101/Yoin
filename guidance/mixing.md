# 混音指导

版本：1。开发用初稿，供作曲合作者补充；运行 agent 时自动注入本轮 prompt。

## 使用原则

- 当前默认优先参考 quiet_reading，使用已有的水滴、鸟叫和翻书素材，留出安静间隙。
- 用户反馈占位雨声嘶声重、刺耳；舒适试听默认避免白噪／粉噪铺底及噪声混响。
- 鸟叫本身有高音，默认放远、降低 brightness 和相对音量，不能为消除掩盖提示就把它调得突出。
- 优先回应用户的新要求，模板提供起点。
- 用连续声音建立背景，音乐可以只提供远处的色彩，偶发声音保持稀疏。
- 分析建议只提示需要检查的地方，允许保留并解释。
- 同一 seed 和稳定 layer_id 保持随机安排可比较；调整时默认保留无关参数。
- 具体音色只能用实际存在的素材表达，不能用解释文字补足缺失的声音。

## 调整词典

| 听感或用户说法 | 建议先尝试 | 注意 |
| --- | --- | --- |
| 雨再远一点 | 增大雨层 distance | 会同时变暗、衰减并增加混响送量 |
| 刺耳、嘶声太多 | 降低 brightness，减少噪声铺底，必要时关闭混响 | 单改所有层 volume 会被总线归一化补回；整体响度由规则调整 |
| 音乐太抢注意 | 拉远或降低音乐层 volume | 不要求消除所有能量占比差异 |
| 太闷 | 提高目标层 brightness | distance 也限制截止频率，可能需要配合试听 |
| 短声太频繁 | 降低 events_per_minute | 0 表示关闭事件 |
| 空间太空旷 | 降低 room.amount 或选择短混响房间 | 房间改变影响所有层 |

## 合作者提交方式

提交模板说明与参考配方，以及“听感问题 → 改动 → 试听结论”的案例。
本轮不要求填写统一的声学阈值。后续评分沿用运行记录，不建立额外评分系统。
