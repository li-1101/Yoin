# 混音指导

版本：1。开发用初稿，供作曲合作者补充；运行 agent 时自动注入本轮 prompt。

## 使用原则

- 当前默认优先参考 quiet_reading，使用已有的水滴、鸟叫和翻书素材，留出安静间隙。
- 用户要水滴时选 `water_drop_single_01`：一次短促的单颗滴声。`water_drop_01` 为旧版细碎水声，默认不再选用；继续调整旧配方时如用户要求水滴，则替换 sound_id 并保留 water 层标识与其他无关参数。
- 用户反馈占位雨声嘶声重、刺耳；舒适试听默认避免白噪／粉噪铺底及噪声混响。
- 鸟叫本身有高音，默认放远、降低 brightness 和相对音量，不能为消除掩盖提示就把它调得突出。
- 优先回应用户的新要求，模板提供起点。
- 用连续声音建立背景，音乐可以只提供远处的色彩，偶发声音保持稀疏。
- 分析建议只提示需要检查的地方，允许保留并解释。
- 同一 seed 和稳定 layer_id 保持随机安排可比较；调整时默认保留无关参数。
- 具体音色只能用实际存在的素材表达，不能用解释文字补足缺失的声音。

## 古典音乐素材

- 用户要求古典音乐或钢琴背景时，可选 `bach_prelude_c_major_01`（巴赫 C 大调前奏曲 BWV 846）或 `satie_gymnopedie_1_01`（萨蒂第一号吉姆诺佩蒂）。两份音源均为 CC0 整曲。
- 默认一次只选一首作背景，不同时叠加不同乐曲；音乐层使用 loop 参数，不填写事件频率。
- 先用较轻的相对音量和较低的 brightness，按用户要求试听后调整；保留录音本身的动态，不用额外的大空间混响铺满声音。
- 库内保留完整曲目，渲染仍按 seed 从现有循环逻辑取段，不保证从曲首开始；当前不做节拍同步或曲式编排。

## 环境声素材

- `ocean_waves_01` 是石滩近处浪涌、拍岸与退浪，适合海边场景的连续底色。
- `wind_leaves_01` 是风吹树叶的环境声；`campfire_01` 是篝火燃烧与噼啪声；`night_crickets_01` 是作者清理过背景噪声的夏夜蟋蟀录音。
- 以上四种均为 loop，不填写事件频率。按用户指定环境优先选择，先用一层背景，再按要求叠加短事件；不默认同时加入四种环境声。
- 虫鸣本身有较高音区，先控制相对音量，保留自然节律；篝火的爆裂声不必额外提亮或加大混响。

## 用户 10.28 采集素材

- 日本城市场景可选 `user_ear0_tokyo_subway_19085`（东京地铁）、`user_ear0_ginza_street_23340`（银座街头）、`user_ear0_kyoto_crosswalk_19789`（京都人行横道）。按用户明确要求选用，不默认加入安静阅读模板。
- 鸟声可选 `user_ear0_crow_13402`、`user_ear0_seagull_19742`、`user_ear0_cuckoo_13845`；海浪可选 `user_ear0_beach_surge_38511`、`user_ear0_ocean_swell_38510`。
- 另有 `user_ear0_train_whistle_11776`（火车汽笛）和 `user_ear0_temple_bell_34166`（寺庙钟声）。这批十项均是连续片段，按 loop 使用，不填写事件频率；不把含多次声音的长片段描述成单声短事件。
- 保留目录中逐项记录的许可。标为待核实的素材，不得在解释中宣称为 CC0 或已确认可商用。

## 调整词典

| 听感或用户说法 | 建议先尝试 | 注意 |
| --- | --- | --- |
| 雨再远一点 | 增大雨层 distance | 会同时变暗、衰减并增加混响送量 |
| 刺耳、嘶声太多 | 降低 brightness，减少噪声铺底，必要时关闭混响 | 单改所有层 volume 会被总线归一化补回；整体响度由规则调整 |
| 音乐太抢注意 | 拉远或降低音乐层 volume | 不要求消除所有能量占比差异 |
| 太闷 | 提高目标层 brightness | distance 也限制截止频率，可能需要配合试听 |
| 短声太频繁 | 降低 events_per_minute | 0 表示关闭事件 |
| 空间太空旷 | 降低 room.amount 或选择短混响房间 | 房间改变影响所有层 |

## 合作者提交方式

提交模板说明与参考配方，以及“听感问题 → 改动 → 试听结论”的案例。
本轮不要求填写统一的声学阈值。后续评分沿用运行记录，不建立额外评分系统。
