# 11 — 扩充海浪等环境声素材

**What to build:** 用户确认保留现有水滴，并要求寻找海浪等几种声音素材。下载海浪、风吹树叶、篝火、夜虫四种 CC0 环境声，登记到声音库，提供单独试听。

**Blocked by:** 07 — 本地试听页；10 — 单颗水滴。

**Status:** done

- [x] 核对四份音源的 CC0 信息，保存原始来源与下载记录。
- [x] 转换为现有渲染器可用的 48000 Hz 音频并登记为 loop。
- [x] 验证素材哈希、实际加载与渲染，提供四段 30 秒单独试听。
- [x] 现有水滴、模板和已生成混音保持原状。

验收：四份原下载和处理后文件的SHA256匹配；48000 Hz、立体声、PCM_24 FLAC加载为float32，均进入实际模型目录。
四次30秒渲染通过，独立试听为PCM_16 WAV，响度约-30 LUFS，峰值低于-9 dBFS；量化误差不超过一个16位采样单位。
与基准80c2a9f逐项比对，原13条声音描述和单颗水滴字节未变；录音与占位素材的8项测试通过。
