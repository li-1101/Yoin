# 03 — 中文场景经过自我调整得到最终音频

**What to build:** 用户输入中文场景，模型通过两个工具试听、调整并提交配方，保存第一版、最终版和完整过程。

**Blocked by:** 02 — 渲染后得到测量与混音建议。

**Status:** ready-for-agent

- [ ] 使用环境变量配置的兼容工具调用接口，无 agent 框架。
- [ ] 最多八轮；出现建议后至少调整一次，允许解释后带建议提交。
- [ ] 声音目录、设计指南和少量模板可以注入 prompt。
- [ ] 第一版和最终版保存相同时长的音频，过程记录及版本快照完整。
- [ ] 未主动提交时使用最后一份有效配方；从未产生有效配方时明确失败并保留过程。
- [ ] 使用模拟模型响应验证循环，不依赖付费服务测试。
