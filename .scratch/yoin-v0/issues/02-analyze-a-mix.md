**What to build:** 用户渲染一份配方后，得到整体和单层测量，以及可配置、允许保留的中文混音建议。

**Blocked by:** 01 — 从手写配方生成占位声音混音。

**Status:** done

- [x] 响度、峰值、能量占比、频段能量和左右能量差可测量。
- [x] 测量和规则判断分离，阈值和规则开关可配置。
- [x] 可能被掩盖、占比高、层数、事件密度和左右差异提供中文建议。
- [x] 静音数据可序列化，结果不含 NaN 或 Infinity。
- [x] 构造遮蔽案例后，调整音量能验证相应建议改变。
